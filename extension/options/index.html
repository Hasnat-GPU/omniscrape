OmniScrape settings

Connection to the local MCP server, and defaults for manual captures.

Bridge

Where the MCP server is listening. The server prints this on startup and serves a health check at the matching http://…/health URL.

Only needed if you set OMNISCRAPE_TOKEN on the server. It stops other local programs from connecting to the bridge and reading your scrapes.

Capture defaults

Used by the side panel's buttons. Claude passes its own options on every tool call, so these do not affect what Claude requests.

Page access

Checking…

Claude can only read a tab when this is granted. Revoking stops all scraping until you grant it again.
